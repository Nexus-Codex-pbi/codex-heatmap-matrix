Codex Heatmap Matrix v1.1.0.32 - resubmission after the 03/08/2026 review (Policy 1180.2.4 Data Types).

Source code repository: https://github.com/Nexus-Codex-pbi/codex-heatmap-matrix
No test account, licence key or in-app purchase required. All functionality is in the attached sample .pbix.

REPORTED: unresponsive on a large dataset (~100,000 rows, numeric column bound to Column Category).

CAUSE: cost scaled with rendered CELLS (uniqueRows x uniqueColumns), not rows. A high-cardinality field on either axis expanded the grid without limit, so at the 30,000 data-reduction cap up to 30,000 cells were built synchronously, blocking the iframe.

FIX 1 - Grid bounded to 5,000 cells / 200 per axis, both axes shrunk proportionally. Truncation is stated on the canvas, never silent: "Showing 70 of 30,000 rows and 70 of 900 columns. Filter the data or use lower-cardinality fields to see all of it." A 200 x 25 grid still renders in full.

FIX 2 - Per-row parse made cheaper (nested index replacing a concatenated key allocated per source row; single map lookups). 1M rows: 285ms to 114ms.

We then audited the rest of 1180.2.4 and fixed two more:

FIX 3 - Blank rendered as zero. Number(null) and Number("") both coerce to 0, so null cells printed "0". Blanks now render empty; a genuine 0 still prints 0.

FIX 4 - Text values rendered blank. Cell Value accepts a text column and Number("North") is NaN. Text cells now display their string on the empty-cell fill, with theming, transparency and conditional formatting applied as for numeric cells. Tooltips show the string. To verify, bind any text column to Cell Value.

VERIFIED UNCHANGED: negatives ramp correctly and stay in the colour domain; large magnitudes render in full; numeric strings ("12.5") still parse as numbers; dataReductionAlgorithm remains 30,000. Twelve input shapes tested, including null, undefined, empty string, whitespace, real zero and string zero.


supportsHighlight is false deliberately: declaring it true without honouring the highlight array is itself a 1180.2.2 finding. It will be set when the renderer genuinely dims un-highlighted cells.

No capabilities.json change - no data role, mapping or property added, removed or altered.
